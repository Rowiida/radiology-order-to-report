How to read these numbers

  • Every order, time and error here was generated by a script with fixed assumptions. No patient or hospital data was used.
  • The script builds in a few patterns: routine night studies wait for the morning, CT and MR take longer to read than X-ray, and 2 to 3 percent of messages fail at each of three handoffs. The dashboard shows that the queries find them, not how a real hospital performs.
  • All timestamps come from one status history table, one row per status change. The same queries would run on real RIS and PACS message logs.
